# 🕌 Website Resmi Yayasan Jannatul Firdaus

Website profil, informasi kegiatan, dan layanan publik untuk **Yayasan Jannatul Firdaus**. Proyek ini dibangun untuk memudahkan masyarakat dalam mengakses informasi seputar program yayasan, pendidikan, kegiatan sosial, serta penyaluran donasi secara transparan.

🌐 **Live Demo:** [yayasan-jannatul-firdaus.vercel.app](https://yayasan-jannatul-firdaus.vercel.app/)

---

## ✨ Fitur Utama

- **Profil Yayasan:** Informasi lengkap mengenai sejarah, visi, misi, dan struktur kepengurusan yayasan.
- **Program & Kegiatan:** Daftar program pendidikan, sosial, dakwah, dan dokumentasi kegiatan terbaru.
- **Informasi Donasi / Wakaf:** Panduan dan informasi rekening resmi untuk memudahkan donatur berpartisipasi.
- **Berita & Artikel:** Publikasi berita terkini dan artikel keislaman/sosial.
- **Kontak & Lokasi:** Informasi alamat lengkap, integrasi peta lokasi, dan kontak pengurus.
- **Desain Responsif:** Tampilan optimal di berbagai perangkat (Desktop, Tablet, maupun Smartphone).
